# Arroyo: asignación de carteras

Repositorio de demostración. Arroyo es una empresa inventada y todos los datos son ficticios.

- `reglas.md`: las reglas con que se asignan las carteras de clientes.
- `traspaso.md`: la nota para quien siga el trabajo.
- `CLAUDE.md`: las instrucciones que Claude lee antes de actuar.
